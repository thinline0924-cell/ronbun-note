# 論文ノート

大学生・大学院生のための、研究の記録から日本語の論文が育っていくブラウザのアプリです。

- **研究資料**:PDF・Word(.docx)・PowerPoint(.pptx)・テキスト(.txt .md .csv)を読み込むと、要約して論文(主に先行研究)に反映します
- **研究ログ**:やったこと・わかったことを書くたびに、関係する章(結果・方法など)が書き進みます
- **論文**:いつでも全文を読めます。自分で直すこともできます。「書き換え禁止」にした章は自動では変わりません
- **締切**:次の締切まで「あと◯日」をホームに表示します
- **書き出し**:Word(.docx)と PDF(印刷の画面で「PDFに保存」)

要約と執筆には Google の Gemini API を使います。

## 大事なこと

- **データはあなたのブラウザの中だけに保存されます。** サーバーには保存しません。
  ブラウザの履歴やサイトのデータを消すと消えることがあるので、「設定」→「バックアップを保存」をときどき押してください。
  別のパソコンに移すときも、このバックアップを使います。
- 資料・研究ログ・論文の本文は、要約や執筆のたびに Gemini API に送られます(保存はしない設定 `store: false` で送っています)。
- 論文の中身は、研究ログと資料に書かれたことだけから作ります。足りない所は【要確認:…】と書かれるので、ログを足すか自分で書き足してください。
- 合言葉(パスワード)は付けていません。URL を知っている人は誰でも使えます。
  使いすぎを防ぐため、同じ回線からの回数を制限しています(資料の要約 10分に20件、論文への反映 10分に40回)。

## 公開のしかた(Render)

パソコンに何も入れなくてもできます。

1. **Gemini の APIキーを用意する**
   [Google AI Studio](https://aistudio.google.com/apikey) で「Create API key」を押し、表示されたキーをコピーします。
   キーは人に見せたり、ファイルに書いたりしないでください。
2. **Render で Blueprint を作る**
   [Render](https://dashboard.render.com/) にログイン → 「New +」→「Blueprint」→ この GitHub リポジトリ `ronbun-note` を選びます。
3. **APIキーを入れる**
   `GEMINI_API_KEY` を聞かれたら、1 でコピーしたキーを貼り付けて「Apply」を押します。
4. 数分待つと公開されます。表示された URL(`https://ronbun-note-xxxx.onrender.com` のような形)を開いてください。

無料プランは、しばらく使わないと止まります。次に開いたときは、表示されるまで1分ほどかかることがあります。

### 設定できる値(Render の Environment 画面)

| 名前 | 内容 |
|---|---|
| `GEMINI_API_KEY` | Gemini の APIキー(必須) |
| `GEMINI_MODEL` | 使うモデル。既定は `gemini-3.8-flash` |

## 困ったとき

| 画面に出た文 | 対処 |
|---|---|
| Gemini の APIキーが設定されていません | Render の Environment で `GEMINI_API_KEY` を設定する |
| Gemini のAPIキーが正しくありません | キーをコピーし直して、もう一度貼り付ける |
| Gemini のモデル「…」が見つかりません | `GEMINI_MODEL` のモデル名を確認する |
| 文字を読み取れませんでした | 写真やスキャンだけの PDF は読めません。文字を選べる PDF か Word で読み込む |
| 古い Word 形式(.doc)は読めません | Word で開いて「.docx」で保存し直す |
